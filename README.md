# A-for-Bridge-Crossing
Implementation of A* algorithm in Java that solves bridge crossing problem. It uses heuristic cost for combination cost instead of Manhattan/Eucledian distance.

## Bridge Crossing Problem:
A family of four needs to cross a narrow bridge at night to reach safety.
- The Bridge Constraints: bridge can only hold up to two people at a time.
- It is pitch black, so anyone crossing must carry a torch/flashlight.
- They have only one torch among them.
- When two people cross together, they must move at the speed of the slower person.
- The Family Members have different Speeds

Goal: Get all four family members across the bridge in an optimal cost.
